# **AniNotify**

> [!CAUTION]
> ВНИМАНИЕ! Программа на данный момент не функционирует из-за изменения API Kodik-а, который используется для поиска.
> Проект полностью опирается на библиотеку [anime-parsers-ru](https://github.com/YaNesyTortiK/AnimeParsers).

>[!IMPORTANT]
> ВАЖНО! Если вы уже использовали программу, и она уже стоит в автозапуске, выключите его через Диспетчер задач или через Registry Editor (regedit), все настройки находятся в "Computer\HKEY_CURRENT_USER\SOFTWARE\Solar\AniNotify", там выберите параметр "startup" и измените на false

Программа для мониторинга новых озвучек для выбранного аниме, отправляющая оповещение на локальный пк. Пока поддерживается только плеер Kodik

### *Использование:*

1) Запустите .exe
2) Следуйте интерфейсу, после сохранения нажмите на кнопку "Выполнить поиск", далее будет запущен процесс на фоне
3) Ждите, при удачном выполнении программы будет выведено оповещение в Windows

*У программы есть трей, позволяющий открыть окно программы, начать процесс поиска и т.п.*
